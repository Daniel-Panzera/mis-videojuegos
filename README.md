# mis-videojuegos

Videojuegos hechos con Python y Pygame durante la cursada.

## Entorno

- Python 3.14.7
- pygame-ce 2.5.8 (edición de la comunidad; se importa igual, con `import pygame`)

Instalación de la dependencia:

```powershell
python -m pip install pygame-ce
```

## Clases

| Carpeta | Juego | Cómo ejecutarlo |
|---|---|---|
| `clase_01_primeros_pasos/` | Ventana con un cuadrado que se mueve con las flechas | `python clase_01_primeros_pasos\juego.py` |
